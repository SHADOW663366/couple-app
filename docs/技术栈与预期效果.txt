情侣向 App — 技术栈与预期效果
更新日期：2026-11-04

一、产品定稿（基于需求确认）
1. 平台：仅移动端（iOS / Android）
2. 账号登录 + 情侣绑定（邀请码 / 扫码）；未绑定仅可单人玩法
3. AI：每人可拥有自己的二次元角色；也可一起与对方角色互动
4. 真心话：问答卡片为主，可选轻度互动挑战（不做重惩罚向大冒险）
   题库 = 本地固定题库 + 按关系阶段 / 亲密度由 AI 生成
5. 日记：可分享给对方、可共同日记；支持图片、语音
6. 交付目标：一上来按较完整产品形态设计（非极简 MVP）

二、技术栈（推荐定稿）

【客户端】
- Flutter 3.x（Dart）
  理由：一套代码双端、动画/二次元表现力好、适合聊天气泡与日记富媒体
- 状态管理：Riverpod
- 路由：go_router
- 本地存储：Hive / shared_preferences（草稿、缓存、题库包）
- 媒体：image_picker、录音插件、缓存播放（语音日记）
- 推送：Firebase Cloud Messaging（或国内厂商推送通道，上线前按商店地区再定）

【服务端】
- 语言：Node.js + NestJS（TypeScript）
- API 风格：REST 为主，实时能力用 WebSocket（聊天、共同日记协同、在线状态）
- 鉴权：JWT + Refresh Token；情侣关系用 pair_id 做资源隔离

【数据与存储】
- 主库：PostgreSQL（用户、绑定、日记、真心话记录、角色配置、亲密度）
- 缓存 / 会话：Redis（在线状态、邀请码短链、限流、AI 会话上下文摘要）
- 对象存储：S3 兼容（图片 / 语音）；国内可切阿里云 OSS / 腾讯云 COS
- 搜索（可选二期）：日记全文检索用 Postgres 全文或 Meilisearch

【AI】
- 对话模型：DeepSeek API（角色扮演、真心话出题、日记轻总结）
- 服务端统一代理调用（禁止把 Key 下发到客户端）
- 角色系统：人设卡（性格、口吻、禁忌、与主人/伴侣关系设定）+ 短期上下文 + 长期记忆摘要
- 安全：敏感内容过滤、情侣场景提示词护栏、按用户限流

【运营与工程】
- 配置中心 / 远程题库包：服务端下发，客户端可热更新本地题库
- 日志与监控：服务端结构化日志 + Sentry（客户端崩溃）
- CI/CD：GitHub Actions / 同类流水线；TestFlight + 内测分发
- 合规：隐私政策、用户协议、媒体权限说明；未成年人与敏感内容策略预留

三、模块预期效果

1. 账号与绑定
- 手机号 / 邮箱注册登录（可先做邮箱 + 密码，手机号验证码按地区补）
- 生成邀请码 / 二维码；对方确认后结成情侣 pair
- 未绑定：仅单人模式（自己的 AI、自己的日记、单人真心话练习）
- 已绑定：双人真心话、共同日记、互访对方 AI、亲密度成长

2. AI 二次元角色
- 每人创建 / 选择角色（立绘、名字、性格标签、说话风格）
- 单人：与自己的角色深度聊天、哄陪伴、根据日记/答题轻度回应
- 双人：可「一起聊」对方角色（三人语境：我、伴侣、角色）；或轮流与对方角色互动
- 角色有表情 / 短句气泡反馈（完整 Live2D 可作为增强项，首版可用立绘差分 + 动画）

3. 真心话
- 模式：单人练习 / 双人轮流
- 抽题：本地固定题库（按亲密度解锁层级）+ AI 按恋爱天数、近期日记主题、亲密度生成个性化题
- 流程：抽题 → 回答（文字 / 可选语音）→ 对方可见（双人）→ 记录进「我们的回忆」
- 轻度挑战卡可选开启（如「今晚互发一句今天最想说的话」），默认关闭重惩罚

4. 日记
- 个人日记：默认可仅自己；一键分享给对方
- 共同日记：同一篇双方可追加文字 / 图 / 语音（类共创时间线）
- 媒体：多图、语音条；列表按日期；支持纪念日标签
- AI：可对单篇或一周日记生成「温柔总结 / 话题建议」（可开关）

5. 感情成长（完整版应具备）
- 亲密度等级、恋爱日计数、共同完成真心话次数
- 简单成就 / 纪念节点（绑定纪念日、连续写日记等）
- 首页：今日一句、未读对方分享、AI 问候入口

四、体验目标（验收观感）
- 打开 App：3 秒内进入首页；聊天首字延迟可控（流式输出）
- 二次元视觉统一：角色立绘、字体、气泡、日记纸感或轻插画风（避免杂乱多皮肤）
- 双人强感知：绑定状态、对方在线、共同内容有清晰归属
- 离线降级：本地题库与草稿可离线写；上线后同步
- 隐私默认保守：分享、共同日记、AI 读日记均需显式同意

五、不在首版硬承诺（可排期）
- 完整 Live2D / 语音克隆 / 视频通话
- 复杂商城与付费皮肤体系（可预留角色皮肤数据结构）
- 多对多社交广场（产品定位为情侣私密空间）

六、成功标准（完整版上线门槛）
- 双端可安装运行；注册登录稳定
- 绑定 / 解绑流程可用且数据隔离正确
- AI 单聊与「一起聊对方角色」可用
- 真心话本地 + AI 出题闭环
- 日记分享 + 共同日记 + 图语音上传播放闭环
- 基础推送（对方分享、真心话轮到你）可用

# 免费公网部署

目标：手机用 WiFi / 流量都能访问。

## 方案 A：临时免费隧道（已在用）

- 地址示例：`https://xxxx.loca.lt`
- 手机流量可用，但**电脑必须开着**（API + 隧道）
- 隧道重启后地址会变，需重打 APK
- 适合先给朋友试用

## 方案 B：永久免费云（不必开电脑）— Render

### 免费档限制

- 约 15 分钟无人访问会休眠；下次打开可能等 30～60 秒
- 当前 SQLite：重启后数据可能清空（够演示）

### 步骤（约 10 分钟）

1. 注册：https://dashboard.render.com/register （可用 GitHub）
2. 把仓库推到 GitHub（至少包含 `apps/api`）
3. Render → **New** → **Web Service** → 选仓库
4. 设置：
   - Root Directory：`apps/api`
   - Runtime：Docker
   - Instance：Free
   - Health Check Path：`/health`
5. Environment：
   - `JWT_SECRET` = 随便一长串
   - `DATABASE_URL` = `file:./prod.db`
6. 部署成功后得到：`https://xxx.onrender.com`
7. 把该地址发回来，重打 APK 即可

### 验证

浏览器打开：`https://你的域名/health`  
应返回：`{"ok":true,"service":"couple-api",...}`

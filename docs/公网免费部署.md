# 免费公网部署

## 推荐：SnapDeploy（不用绑卡）

官网：https://snapdeploy.dev

### 限制

- 约 15 分钟没人访问会休眠；下次打开可能等约 1 分钟
- 免费约 100 容器小时/月
- 适合演示；正式 24 小时在线需付费 Always-On

### 步骤

1. 打开 https://snapdeploy.dev ，用 **GitHub** 登录（不用信用卡）
2. **Deploy from GitHub** → 选仓库 `SHADOW663366/couple-app` → 分支 `main`
3. 若有 Dockerfile / Docker 选项，选用仓库根目录的 `Dockerfile`
4. 环境变量添加：
   - `JWT_SECRET` = `couple-secret-2026-change-me`
   - `DATABASE_URL` = `file:./prod.db`（演示够用；**容器重建会丢数据**）
5. Deploy，等健康检查通过
6. 复制地址（形如 `https://xxxx.containers.snapdeploy.app`）发回来重打 APK

### 验证

浏览器打开：`https://你的域名/health`  
应看到：`{"ok":true,"service":"couple-api",...}`

### 数据不丢（后续）

- 日记图/语音已存进数据库（不再依赖容器 `uploads` 目录）
- 要跨部署不丢：把 `DATABASE_URL` 换成免费 Postgres（如 Neon / Supabase），Prisma 已兼容切换
- 大文件可再接 Cloudflare R2 等对象存储

# 登录 / 日记会不会被部署刷掉？

## 结论（当前 SnapDeploy 免费容器）

**会。** 现在数据库是容器里的 SQLite 文件（`DATABASE_URL=file:./prod.db`）。

下面这些情况可能让账号、绑定、日记、聊天记录清空，需要重新注册：

- 重新 Deploy / 换镜像重建容器
- 平台回收实例、换机器
- 误改/清空磁盘

**不会因为「你平时打开 App、对方登录」就刷新掉**——只有云端实例被重建时才会丢。

日记文字和新媒体附件都在这个库里；比早期「附件只在 uploads 目录」稳一点，但**整库仍会随容器一起丢**。

## 真正不丢：接免费 Postgres（推荐 Neon）

1. 打开 https://neon.tech 注册，新建项目，复制连接串（`postgresql://...`）
2. SnapDeploy 环境变量把 `DATABASE_URL` 改成这条 Neon 连接串  
   （并保留 `JWT_SECRET`；可选 `DEEPSEEK_API_KEY`）
3. 仓库 Prisma 需切到 `postgresql` 再部署（需要我改代码时直接说「切 Postgres」）
4. 之后重建容器也只丢代码实例，**数据在 Neon 上保留**
